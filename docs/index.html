keyboard-fix

کیبورد اشتباه؟ یک کلید بزنید.

متنی که با چیدمان اشتباه نوشته‌اید، در جا به زبان درست برمی‌گردد: sghl می‌شود «سلام» و صاشف می‌شود «what». روی مک و ویندوز، در هر برنامه‌ای.

همین‌جا امتحان کنید

نتیجه

جهت تبدیل خودکار از روی حروف تشخیص داده می‌شود. اگر پ یا ئ اشتباه شد، چیدمان قدیمی ویندوز را انتخاب کنید:

نصب، سه قدم

مک

Hammerspoon · فایل init.lua
دانلود برای مک
  1. Hammerspoon را نصب کنید و در System Settings → Privacy & Security → Accessibility به آن اجازه بدهید.
  2. فایل را در پوشهٔ ~/.hammerspoon بگذارید (در Finder: ⇧⌘G و تایپ مسیر).
  3. از آیکون چکش در نوار بالا Reload Config را بزنید. کلید: Fn+F8.

ویندوز

AutoHotkey v2 · فایل fix-keyboard.ahk
دانلود برای ویندوز
  1. AutoHotkey نسخهٔ ۲ را نصب کنید.
  2. روی فایل دوبار کلیک کنید. کلید: F8.
  3. برای اجرای خودکار، میان‌بر فایل را در پوشهٔ shell:startup بگذارید.

متن را انتخاب کنید و کلید را بزنید؛ اگر چیزی انتخاب نباشد، از اول خط تا مکان‌نما تبدیل می‌شود. کلیپ‌بورد بعدش به حالت قبل برمی‌گردد. کلید و چیدمان در چند خط اول هر فایل قابل تغییر است.

Wrong keyboard? Press one key.

Text typed with the wrong layout is converted in place: sghl becomes «سلام», صاشف becomes "what". macOS and Windows, in any app.

Try it here

Result

The direction is detected from the letters. If پ or ئ come out wrong, pick the old Windows layout:

Install in three steps

macOS

Hammerspoon · init.lua
Download for macOS
  1. Install Hammerspoon and allow it under System Settings → Privacy & Security → Accessibility.
  2. Put the file in ~/.hammerspoon (in Finder: ⇧⌘G, then type the path).
  3. Hammer icon in the menu bar → Reload Config. Key: Fn+F8.

Windows

AutoHotkey v2 · fix-keyboard.ahk
Download for Windows
  1. Install AutoHotkey v2.
  2. Double-click the file. Key: F8.
  3. To run at login, put a shortcut to it in shell:startup.

Select text and press the key; with nothing selected, the line up to the cursor is converted. The clipboard is restored afterwards. The key and layout are settings in the first lines of each file.
